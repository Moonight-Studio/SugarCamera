使用支持

糖水相机支持拍照、从系统照片选择器导入照片、切换原片或六种轻量滤镜，以及将处理结果保存到系统相册。

如何使用滤镜

先拍照或导入照片，再选择“原片”、自然、清透、甜美、冷白、胶片或暖阳。实时取景画面暂不叠加滤镜。选择满意的效果后点击保存。

权限与常见问题

拍照需要允许相机权限；保存需要允许添加照片权限。若无法使用，请在 iOS“设置”中检查糖水相机的权限。导入照片通过系统照片选择器，只读取你主动选取的图片。

联系支持

请通过 GitHub Issues 提交问题或建议，附上设备型号、iOS 版本、操作步骤及错误提示。Issues 是公开的，请勿提交私人照片、联系信息或其他敏感内容。

隐私问题也可通过上述 Issues 联系我们。查看隐私政策。
